# dreamdeck

DreamDeck (Arbeitstitel) ist eine Bedienoberfläche für die Bildgenerierung mit ComfyUI. Sie steuert ComfyUI über dessen API und läuft auf einem RunPod-Pod, der nur bei Bedarf gestartet wird. Der Stand ist Planung; es gibt noch keinen Programmcode.
